= RISC-V Timing Fences Guide

This directory contains the source and build configuration for _Understanding
and Mitigating Covert Channels_, a non-normative guide produced by the RISC-V
Timing Fences Task Group. The proposed instruction semantics are maintained in
link:../extension/Zifencetime.adoc[`extension/Zifencetime.adoc`].

== Build the guide

The supported build uses the Nix shell defined in `env/shell.nix`. It produces
`guide/build/main.html` and `guide/build/main.pdf`, relative to the repository
root.

=== Clone with SSH

[source,shell]
----
git clone --recurse-submodules git@github.com:riscv-admin/timing-fences.git
cd timing-fences/guide
nix-shell env/shell.nix --run 'make all-nix'
----

=== Clone with HTTPS

Use this form when SSH access is not configured:

[source,shell]
----
git clone --recurse-submodules https://github.com/riscv-admin/timing-fences.git
cd timing-fences/guide
nix-shell env/shell.nix --run 'make all-nix'
----

For an existing checkout, initialize or update the required submodules before
building:

[source,shell]
----
git submodule update --init --recursive
cd guide
nix-shell env/shell.nix --run 'make all-nix'
----
